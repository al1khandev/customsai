# TN VED Classifier для таможенной декларации в Казахстане

Production-ready модуль для классификации товаров по ТН ВЭД ЕАЭС с консервативным подходом к безопасности.

## 🎯 Особенности

- **Консервативный подход**: лучше задать вопрос, чем выдать рискованный код
- **Chain-of-Thought**: пошаговое обоснование каждого решения
- **Few-shot learning**: обучение на реальных ошибках и исправлениях
- **Детектор материалов**: автоматическое определение (EVA, TPE, мембрана, кожа и т.д.)
- **Детектор функций**: распознавание медицинских, бытовых, электронных функций
- **Уточняющие вопросы**: автоматические вопросы для сложных случаев
- **Безопасные коды**: приоритет кодам, которые часто проходят на таможне Казахстана (2025-2026)

## 📖 Использование

### Базовое использование

```python
from tnved_classifier import TNVEDClassifier

# Инициализация
classifier = TNVEDClassifier()

# Классификация
result = classifier.classify("Смарт-часы с ЭКГ, давлением, SpO2")

# Вывод результата
print(classifier.format_result(result))
```

### Результат классификации

```python
# Структура результата
result.main_code              # Основной код (10 знаков)
result.alternative_code       # Альтернативный код (если есть)
result.description            # Описание кода
result.rationale              # Обоснование выбора
result.confidence             # ConfidenceLevel (HIGH/MEDIUM/LOW)
result.clarification_questions # Список уточняющих вопросов
result.analysis_steps         # Шаги анализа (Chain-of-Thought)
```

## 🔧 Интеграция с WhatsApp-ботом

```python
# Пример для WhatsApp-бота (Python)
from tnved_classifier import TNVEDClassifier

classifier = TNVEDClassifier()

async def handle_tnved_request(user_message: str) -> str:
    """Обработка запроса на определение ТН ВЭД"""
    
    result = classifier.classify(user_message)
    
    # Если есть уточняющие вопросы - задаем их
    if result.clarification_questions:
        questions_text = "\n".join(
            f"{i}. {q}" for i, q in enumerate(result.clarification_questions, 1)
        )
        return f"❓ Для точной классификации уточните:\n{questions_text}"
    
    # Если уверенность низкая - просим больше информации
    if result.confidence == ConfidenceLevel.LOW:
        return "⚠️ Требуется больше информации. Опишите материал, назначение и функции товара."
    
    # Возвращаем результат
    return classifier.format_result(result)
```

## 📚 Архитектура

### MaterialDetector
Детектор материалов из описания товара:
- Полимеры: EVA, TPE, PVC, полиэтилен и т.д.
- Ткани: хлопок, шерсть, синтетика, мембрана
- Кожа: натуральная, искусственная, замша
- Металлы: алюминий, сталь
- И другие материалы

### FunctionDetector
Детектор функций и назначения:
- Медицинские: ЭКГ, SpO2, TENS, массажёр
- Электронные: Bluetooth, Wi-Fi, GPS, камера
- Бытовые: пылесос, холодильник, сушилка
- Спортивные: йога, фитнес
- Автомобильные и промышленные

### TNVEDClassifier
Основной классификатор с Chain-of-Thought:
1. Предварительный анализ описания
2. Детекция материалов
3. Детекция функций
4. Поиск в базе few-shot примеров
5. Применение правил интерпретации ГИП
6. Проверка безопасности кода
7. Определение альтернативного кода

## ⚠️ Важные правила безопасности

### Правило 1: БАД ≠ Лекарства
- **ОПАСНО**: 3004909090 (лекарственные средства)
- **БЕЗОПАСНО**: 2106909803 (пищевые продукты, БАД)

БАД классифицируются как пищевые продукты, а не лекарства. Код 3004 требует сертификаты и лицензии.

### Правило 2: Основное назначение
Смарт-часы с медицинскими функциями → 9102120000 (часы), а не 9018 (медицинское оборудование).

### Правило 3: Материал определяет группу
- EVA → 3926909090 (пластмасса), не 6306 (текстиль)
- TPE → 4016910000 (резина) или 3926909709 (пластмасса)

### Правило 4: Бытовой vs Промышленный
- Робот-пылесос → 8508110000 (бытовой с аккумулятором)
- Автомобильный компрессор → 8414809000 (бытовой/автомобильный)
